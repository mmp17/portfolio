★ Flagship System

AMR Control System (ACS)

Principal Software Engineer · Robotics Technology Company, Seoul · Sep 2026 – Present
1. Order Ingestion → 2. ACS Mission Dispatch → 3. ROS 2 / Nav2 Fleet → 4. PLC Safety Interlocks → 5. FlexSim Digital Twin

A vendor-agnostic control system for autonomous mobile robot (AMR/AGV) fleets. It orchestrates high-throughput factory orders into executable multi-robot missions, tracks real-time spatial execution, handles exception recovery, and maintains audit traceability.

Challenge
Operating AMR fleets requires an intelligent middle layer between MES/WMS factory operations and autonomous robots. Missions must be scheduled without deadlock, dispatched over ROS 2 networks, synchronized with automated equipment (PLCs, doors, lifters), and provide operators with instant visibility and failover recovery.
Architecture & Contribution
  • Operations Dashboard & Backend: Next.js & TypeScript client on a containerized FastAPI backend with PostgreSQL, providing mission control, station mapping, live telemetry over WebSocket, and alarm management.
  • Mission Lifecycle Engine: End-to-end tracking from order intake through dispatch, execution, exception recovery, and immutable audit logs.
  • Fleet & Robot Adapters: Modular adapter architecture integrating ROS 2 fleets, Nav2 navigation stacks, AMCL localization, and SLAM Toolbox.
  • Industrial Automation: Interfacing with PLC and IoT equipment via industrial communication protocols for door controls, station interlocks, and safety signals.
  • Digital-Twin Validation: Continuous workflow synchronization with FlexSim simulation models to benchmark KPIs: throughput, queue times, and fleet sizing.
Tech Stack
Next.js TypeScript FastAPI PostgreSQL WebSocket Docker ROS 2 Nav2 AMCL SLAM Toolbox PLC / IoT FlexSim
